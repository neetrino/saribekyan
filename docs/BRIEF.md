# Նախագծի տեխզադրանք

## Նկարագրություն

Սարիբեկյան միջազգային բժշկական համալսարանի պաշտոնական վեբ կայք։
Ներկայացնում է համալսարանի գործունեությունը, կրթական ուղղությունները,
ընդունելությունը, կլինիկաները, նորությունները և միջազգային համագործակցությունը։

## Թիրախային լսարան

- Դիմորդներ (ՀՀ և միջազգային)
- Ուսանողներ և ծնողներ
- Գործընկեր հաստատություններ
- Հանրություն

## Հիմնական ֆունկցիաներ (առաջնայնացված)

1. Գլխավոր էջ + հիմնական բաժիններ (Figma) — բարձր
2. Նորություններ / հայտարարություններ (CMS, PostgreSQL) — բարձր
3. Ընդունելություն (քայլեր, փաստաթղթեր, վարձեր, առցանց դիմում) — բարձր
4. Կրթական ուղղություններ և կլինիկաներ — միջին
5. Բազմալեզու (ՀՅ / EN) — միջին
6. Ադմին CMS — միջին (հետագա փուլ)

## Stack

- **Տարբերակ A** — fullstack Next.js (App Router) + PostgreSQL (Prisma)
- Responsive: mobile / tablet / laptop / desktop
- Արագ բեռնում: RSC, `next/image`, օպտիմիզացված ֆոնտեր
